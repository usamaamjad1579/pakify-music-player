# 🎵 Pakify Music Player

A responsive music streaming interface inspired by modern music apps, focused on Pakistani music. Built with plain HTML, CSS and JavaScript, with no frameworks.

![HTML5](https://img.shields.io/badge/HTML5-E34F26?logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?logo=css3&logoColor=white)
![JavaScript](https://img.shields.io/badge/JavaScript-F7DF1E?logo=javascript&logoColor=black)

## Features

- Play, pause, next and previous track controls
- Seek bar and volume control that update in real time
- "Recently played" list that updates as you listen
- Sections for trending songs, Pakistani classics, pop hits and featured playlists
- Light and dark theme switch
- Keyboard shortcuts

## Run it

Open `Music Website/index.html` in a browser. No build step is needed.
